# Python Variables and Data Types

## Explanation

This program demonstrates how variables are created in Python and how different types of data can be stored in them.

## Problem Statement

Write a Python program to create variables of different data types and display their values and types.

## Features

* Demonstrates variables
* Demonstrates integer data
* Demonstrates floating-point data
* Demonstrates string data
* Demonstrates boolean data
* Uses the `type()` function

## How It Works

Python allows variables to store different types of values without explicitly declaring their data type.

The `type()` function is used to identify the data type of a variable.

## Technologies Used

* Python 3

## Program Flow

1. Create variables with different values.
2. Store integer, float, string, and boolean values.
3. Display each value.
4. Display the data type of each variable.

## Sample Input

No input is required.

## Sample Output

```text
Age: 20
Type: <class 'int'>

Height: 5.6
Type: <class 'float'>

Name: Harini
Type: <class 'str'>

Student: True
Type: <class 'bool'>
```
